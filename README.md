## About Me

I work as an MIS Executive, where my day-to-day involves managing operational data — export documentation, inventory tracking, and process reporting — largely through Google Sheets and Apps Script. A big part of my job is turning repetitive, manual spreadsheet work into automated workflows.

Over time I realized that knowing *how to use* Excel isn't enough — understanding *why* the data looks the way it does is what actually matters. That realization pushed me toward data analytics.

Now, alongside my job, I'm building skills in SQL, Python, and data analytics with GenAI tools — not to add keywords to a resume, but because I already work with operational data every day, and I want to move from just reporting it to actually analyzing and drawing insights from it.

I started on GitHub last month. Eight repositories in, and I'm not stopping.
